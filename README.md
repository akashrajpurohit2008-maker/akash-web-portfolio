# Akash — Selected Web Projects

A responsive portfolio with a lightweight CSS 3D hero and four project showcases. The project sites are included under `projects/`, so each one works from the same static host.

## Included projects
- `projects/pathprism/` — PathPrism career guidance site
- `projects/jaipur-caterers/` — Jaipur Caterers website
- `projects/jenesis-jalcare/` — Jalcare's Jenesis site and its stylesheet/logo
- `projects/padamshree/` — Padamshree site, product catalogue, alternate landing page, and logo

The duplicate Jaipur Caterers HTML file found inside the Jenesis folder was identical to the standalone Caterers copy, so it is represented once. Non-website files (.py exercise and image-only HTML snippet) were left out.

## Publish with GitHub Pages
In Settings → Pages, choose Deploy from a branch, then select main and / (root). This repository is private; public Pages visibility requires a public repository or a plan that supports Pages from private repositories.
